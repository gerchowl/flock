Workbench wireframes

Low-fidelity frames for the flock GUI proposal (ADR-0038): tiles, the inbox, artifacts with feedback, collapse to the rail, the goal tree, the stale state and the phone layout. Names, counts and agents are examples. Numbered circles refer to the notes under each frame.

Workbench

frame · main
  1. Sidebar trees: Fleet (node, agent), Goals, Projects, all under the scope toggle. Nodes are merged by node id (#1076).
  2. Inbox: open questions, permission prompts and feedback requests across agents, blocking first.
  3. Rail: collapsed tiles keep a live badge only if they show one; the rest unsubscribe until restored.
  4. Every row opens its subject in a tile; the kind picks the default tile.

Feedback request

frame · feedback
  1. An agent's flock_artifact_request_feedback is a question about an artifact; it shows inline and in the inbox.
  2. Open artifact calls expand_into_second: a sibling split beside the transcript. The artifact runs in an opaque-origin sandbox under untrusted chrome.
  3. A comment anchors to a block id and is queued to the agent as input; Approve answers the question atomically.

Permission prompt

frame · permission
  1. Fixed choices map to indices server-side; the client never composes keystrokes. A stale answer comes back failed with the current state.

Collapse and rail

frame · rails
  1. The sidebar collapses to icons.
  2. Tiles collapse to chips with a state dot and the last change; tap to restore in place.

Goal tree

frame · goals
  1. Phase 1 is a projection of goal records, delegate edges and the issues and PRs they name; no new storage.

Stale and reconnect

frame · stale
  1. Stale keeps content readable behind a marker and blocks actions.
  2. The outbox shows pending commands; they resend with the same id on reconnect, and the server's idempotency window dedupes.

Phone

frame · mobile
  1. One tile at a time; the accessory row drives the composer (Tauri shell).
  2. Rails and the inbox become bottom sheets; expand_into_second pushes the second tile with a back gesture.
