- `flk delegate wait` no longer reports `no_result` because the server stopped answering. Time the server spends not answering no longer counts against the reply grace: the wait keeps asking, and ends at `--timeout` (124) or, after 5 minutes without an answer, as `server_unavailable` (exit 75), never as a verdict on an agent that may still be working. While the agent works on a server with `events.read`, `--silence` now fires when its window ends rather than up to 10 s later (#1121, #1030)
