- Breaking: four exit codes move to the values ADR-0029 §2 assigns them, so one code means one thing across every verb (#1025). A script that branches on an old code needs a one-line change. For this release each moved case also prints `note: exit code is now N (was M); see CHANGELOG` on stderr; stdout, including `--json` output, is unchanged.
  - refused before acting, nothing changed (an error whose retry class is `later`: `not_settled`, `input_not_empty`, `operator_active`, `injection_pending`, …) from the send-like and guarded verbs (`agent send`, `pane send-text`, `pane submit`, `pane run --if-input-empty`, `pane stash restore`, `msg send`, `msg reply`), from `delegate send` (registry restored), and from `delegate start` when it rolled back (a start kept with `--keep-on-failure` still exits 1): 1 → 10. Other verbs keep 1 for the same errors
  - `agent wait` / `wait agent-status --status settled`, the agent is blocked on a dialog: 3 → 6, the code `delegate wait` already used for the same signal
  - `delegate start --await` / `delegate send --await` / `delegate wait`, `not_started`: 8 → 11
  - `wait reply`, `msg send --await` and `msg status`, the receiver refused the message: 4 → 13
