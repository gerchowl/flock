- A read or delivery receipt that a collect-only spoke owes its dialer no longer waits up to 299 s when the spoke's wake push is lost, for example while the held stream is down and the dialer polls one-shot. The spoke's summary now reports that receipt debt as pending outbound work, so the dialer collects it on its next summary poll. The flag clears once a single poll has taken the receipts, so it cannot keep an idle edge polling (#780)
