- `agent.get` and `agent.list` records (CLI JSON, socket, MCP `flock_agent_get` / `flock_agent_list`) carry a `state` object from ADR-0028 §1 (#1019): `turn` (`working` / `idle` / `unknown`), `lifecycle` (`live` / `hibernated` / `offline`), a derived `phase`, `held_ms` (how long the phase has held; absent for `hibernated` / `offline` for now) and a `source` per observed axis (`screen`, `hook`, `plugin`). `phase` follows the ADR's precedence table with a 20-second settle window: an idle turn reads `settling` until it has held 20 seconds. `background` and `attention` are `unknown` in this release, so a settled idle agent reads `phase: unknown` rather than `finished`, and a visible permission or trust prompt (`agent_status: blocked`) reads `turn: unknown`. `agent_status` is unchanged. A client reads an axis it cannot parse as `unknown` and keeps the others. Remote `fleet` rows read all `unknown`; the mesh protocol is unchanged.
