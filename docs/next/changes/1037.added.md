- Channel adapter contract, first part (#1037, ADR-0028 §8). Declare external channel bindings as `[[channels]]` entries with `name`, `owner_node`, `target` (`fleet`, `repo:<name>` or `agent:<id>`) and `scopes` (`notify`, `send_to_agent`, `reply`). The owner node issues a capability token per binding into `<data dir>/channel-tokens/<name>.token` (mode 0600) at startup and on reload. Delete the file to revoke the binding, and reload to rotate its token. An adapter starts with the new `channel.hello` socket method, or `flk adapter hello <binding>`. A wrong token or an unknown binding is refused with `channel_unauthorized`, a binding served by another node with `channel_not_owner`, and every hello is logged without the token. Protocol 29: against an older server the hello exits 78 (`server_version_gap`) before it is sent, so an adapter refuses to start. Inbound mail (#1153) and the coalesced outbound feed (#1154) follow.
