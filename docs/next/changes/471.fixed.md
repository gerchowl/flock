- `flk server live-handoff` hands off sessions with more than 64 panes instead of refusing with `live handoff supports at most 64 panes in one update`. Pane terminals now cross in batches of 64, and a transfer that fails part-way still leaves every pane with the old server. The old server does the sending, so the first move off an older build still meets its 64-pane check: close panes down to 64 once, or restart normally. On Linux a soft open-file limit of 1024 allows about 450 panes; past that the handoff fails cleanly (#471)
