- `flk goal arm|status|pause|resume|stop` and the socket methods `goal.arm`, `goal.status`, `goal.pause`, `goal.resume` and `goal.stop` (#1155, ADR-0030 §1), the second slice of goal supervision. They change and read the per-agent goal record: arm a goal with its frozen checks, pause it for `--minutes` or until resumed (recorded as `goal_paused` and `goal_resumed`), and stop it. `--agent` defaults to `self`, the agent whose pane runs the command. The operator may change any agent's goal and an agent only its own; another agent, or a caller the server cannot attest, is refused with `goal_caller_refused`. New error codes `goal_not_armed`, `goal_already_armed`, `goal_not_paused` and `goal_caller_refused` exit 1. Protocol 30: the four writes exit 78 against an older server before anything is sent, and `goal status` exits 78 through the version-gap diagnosis. Nothing acts on a goal yet: the stop ladder comes in #1157, the MCP tools in #1156.
