- Report a forwarded message's terminal refusal to its sender: when the owning node behind a hub refuses with `msg_not_allowed` or `recipient_gone`, it returns a receipt it signs itself. The hub routes that receipt back, so the sender's `msg.status` shows `refused` with the reason, or `recipient_gone`, instead of staying in `custody` until expiry. Origins accept only the recipient's own signature, so a hub cannot mint a refusal. (#872)
