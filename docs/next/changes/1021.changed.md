- Pane verbs take the same targets as agent verbs (#1021): `flk pane get`, `rename`, `split`, `move`, `run`, `stash` and `pane.submit` resolve a pane id, terminal id, unique agent name or label, an agent id, or `self` (the caller's own pane, by process ancestry) through the one resolver, on the CLI and on the socket API alike. Against an older server the CLI resolves a name through `agent.get` first, so it works there too. MCP `flock_msg_send` accepts a bare string `to` such as `"w3:p2"` or an agent name besides the structured object; a bare agent id is sent as the `agent` shape. An unknown target is refused with `data.expected` listing the accepted shapes, as is a `to` of the wrong shape.
