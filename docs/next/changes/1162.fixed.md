- Automated text no longer merges into an operator's half-typed draft in an agent pane (#1162). **Behaviour change for automated callers:** `pane run`, `pane send-text` and `agent send --no-submit` into an agent pane (Claude Code, Codex, OpenCode) whose composer holds a draft now refuse with `input_not_empty`, exit 10, before typing anything, and `pane run` then presses no Enter. While a flock injection holds the pane they refuse with `injection_pending`. Shell panes, and agent panes with an empty composer, behave as before: `pane run` still types, waits 120 ms and presses Enter with no idle requirement and no confirmation. `--raw` (socket `"raw": true`) types regardless. To submit a prompt and confirm the turn started, use `agent send`, which also moves a one-row draft aside and types it back. A refused `pane run` exits 10 where it used to exit 1.
