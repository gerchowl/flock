- Automated text no longer merges into an operator's half-typed draft in an agent pane (#1162). `pane send-text`, `agent send --no-submit` and the typed step of `pane run` refuse with `input_not_empty` (exit 10) before typing when the agent's composer (Claude Code, Codex, OpenCode) holds a draft, and with `injection_pending` while a flock injection holds the pane. `pane run` into an agent pane now takes `agent send`'s guarded submit, which moves a one-row draft aside and types it back, and refuses a multi-row or chip draft. Shell panes are unaffected. `--raw` (socket: `"raw": true`) restores the old typing. `pane run`'s refusals now exit 10 instead of 1.
