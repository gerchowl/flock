- `flk delegate list [--mine | --architect <id> | --all] [--branch <b>] [--json]` lists the delegates an architect started, grouped per architect (`--all` for every architect), from the server's new `delegate.list` verb. Each row shows the delegate's status, harness, branch, the PR the poller last saw, the edge's age, and an edge state: `live`, `hibernated, awaiting merge`, `gone`, `gone, worktree retained`, `orphaned`, or `closed, not merged` (a PR closed without merging, batch-landed ones included). It reads only cached state, so it runs no git or `gh` command. MCP `flock_delegate_list` returns the same rows, read-only (#960)
