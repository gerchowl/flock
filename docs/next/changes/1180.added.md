- A delegate's question tool no longer draws a dialog in a pane nobody watches (ADR-0034 §3, §4). `flk integration install claude` adds a `PreToolUse` entry on `AskUserQuestion|ExitPlanMode` that asks the server for a verdict through the new `hook.decide` socket method: an operator-started agent's dialog draws as before, a delegate's call is refused with "state the question and options in your final message and end your turn", and an agent started with `--questions deny` is refused with the disabled-questions sentence. When the server is stopped, silent or older, or `flk` is missing, crashes, prints bad output or hangs, a hinted delegate is still refused with a fixed fallback sentence and a root passes within 500 ms. On Claude Code 2.1.295 or newer the entry carries `onFailure: "block"`. New `[questions] human_tools` lists third-party ask-a-human tools to refuse the same way. The Claude integration asset moves to version 11; run `flk integration sync`.
