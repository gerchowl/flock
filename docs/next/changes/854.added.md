- `flk pane arm-self-compact --instructions <text>` (or `--instructions-file <path>`) and the `instructions` argument of the `flock_self_compact` MCP tool / `pane.arm_self_compact` socket verb carry what the compaction's summary must keep: flock types `/compact <instructions>` in one paste instead of a bare `/compact`, so an agent can steer its own summary (goal, status file, open PRs, standing rules) rather than relying on the harness's default. One line of plain text, capped at 16 KiB, Claude Code only; a harness whose compact command takes no argument is refused rather than armed into a summary that ignores them. Omitting it behaves exactly as before. The field is additive (no protocol bump): a server that stored the instructions answers `instructions: true`, and a client that gets an `armed` from an older server without that flag aborts the arming and exits 78 instead of reporting success (#854)
