- After a compaction or resume, an architect gets its delegate table back as hook output: flock's SessionStart hook asks the server for `delegate list --mine` and, when there are open edges, returns at most 10 rows plus a `+k more: flk delegate list --mine` line. Claude Code and Codex receive it as SessionStart `additionalContext`, opencode's plugin adds it to the compaction context, and nothing is typed into the pane, so unarmed auto-compactions get it as well as armed self-compactions. A harness without a session-start hook gets none; its architect calls `flock_delegate_list` itself (#962)
