- `flk agent send <target> <text>` now submits by default (#995): it runs the guarded submit that `--submit` used to opt into (empty idle composer, Enter after 120 ms, one Enter retry, confirmed turn), and exits 8 (`unconfirmed`) or 9 (`abandoned`) when it cannot confirm the turn. `--no-submit` types only, as plain `agent send` did before. `--submit` is still accepted and changes nothing. Scripts that sent text and then pressed Enter with `pane send-keys … Enter` should drop the second step, or pass `--no-submit` to keep it. A long paste that Claude Code folds into `[Pasted text #N]`, or Codex into `[Pasted Content …]`, now counts as the sent text: it gets the Enter and its one retry, and a chip still in the composer after both is reported as `unconfirmed` with reason `typed_not_submitted` instead of refusing to press Enter (`owned_composer_not_visible`).
