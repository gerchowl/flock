- `agent.get`'s `state.attention` now carries the question when a Claude Code `AskUserQuestion` form or a Codex `request_user_input` form is on screen (ADR-0028 §8a): `needs_human { reason: question, question: { question_id, source, harness, header?, prompt, options: [{ id, label, description? }], multi_select, allow_other } }`. `question_id` stays the same across redraws and changes for a new dialog. New durable kinds `agent.question_opened { agent_id, pane, question_id, question }` and `agent.question_closed { agent_id, pane, question_id, reason: withdrawn }` are emitted at once, with no settle window. On screen, an answer typed at the pane cannot be told apart from a cancel, so it also closes as `withdrawn`. Older servers skip the new kinds in the log (#1038)
