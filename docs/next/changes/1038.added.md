- `agent.get`'s `state.attention` now carries the question when a Claude Code `AskUserQuestion` form or a Codex `request_user_input` form is on screen (ADR-0028 §8a): `needs_human { reason: question, question: { question_id, source, harness, state: open, header?, prompt, options: [{ id, label, description? }], multi_select, allow_other } }`. `question_id` is derived from the agent, the turn cursor and a whitespace-folded fingerprint, so a redraw or a rewrap keeps it, a torn frame does not close the question, and a restart or a live handoff keeps it for a dialog still on screen. New durable kinds `agent.question_opened { agent_id, pane, question_id, question }` and `agent.question_closed { agent_id, pane, question_id, reason: withdrawn, question }` (the question with `state: withdrawn`) are emitted at once, with no settle window. On screen, an answer typed at the pane cannot be told apart from a cancel, so it also closes as `withdrawn`. Older servers skip the new kinds in the log (#1038)
