- `flk delegate wait` (and `start`/`send --await`) no longer reports `no_result` (exit 5) while a Claude delegate is still working (#1257). When the screen read idle mid-turn — every Claude pane did for a minute after a TUI client detached — the await settled, found no reply inside its grace and called the round empty. `agent.result` now reports `turn_open_at_ms` (also as `data.turn_open_at_ms` on a `no_result` refusal) while Claude's transcript records the newest turn as still running, and the await settles again instead of ending the round. Claude's `finished` now waits for the transcript's own end-of-turn record (`turn_duration`, or the interruption notice) once a session has written one, so a narration between two tool calls is no longer read as the turn's reply. Transcript times keep their milliseconds.
