- Accepted ADR-0036 (#1299) with the owner's decisions of 2026-10-13. Agents can run as structured `claude -p` stream-json sessions. flk owns the process and one input queue per agent, which humans and agents share. Queued items stay editable and reorderable, wait in named stashes, and go one batch per turn. Questions do not block unless a System One check finds the agent has nothing else to do, and each question has a stable id. Clients render messages and state over one WebSocket contract, with a Solid reference client. Permission presets can be switched at runtime. Forks can start at any message boundary. The record carries the measured evidence, including the confirmed one-hour cache lifetime. No behaviour changes.
