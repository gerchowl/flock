- Proposed ADR-0036 (#1299): agents can run as structured `claude -p` stream-json sessions. flk would own the process and one input queue per agent, and map the event stream onto agent state, questions and waits. One WebSocket contract with seq cursors and blobs by hash would serve the TUI and a Bun/TypeScript web client. Forks could start at any message boundary. The record carries the measured evidence: hook isolation, permission and question round-trips, the fork cache matrix, and the Codex and opencode event shapes. No behaviour changes.
