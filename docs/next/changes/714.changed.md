- Delegate System One advice works with the Clef models that replaced Kev (#714). Only the `answers` field of a response is read. The default `[systemone] timeout_s` rises from 3 to 4 seconds, sized from clef-flash's measured 1.5-second p95. An endpoint that refuses the request (HTTP 4xx, such as Clef's 400 for a state past its context limit) or reports a truncated state now prints `System One at <url> …` on stderr instead of failing silently. `tier = "full"` with `full_urls`, `SYSTEMONE_URL_FULL` and `full_timeout_s` (default 12 seconds) opts into the larger model; the fast tier stays the default.
