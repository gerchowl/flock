- The server emits durable supervisor events derived from each local agent's `state` (ADR-0028 §2): `agent.phase_changed { agent_id, pane, from, to, state, held_ms }` once a phase has held for the 20 s settle window, plus `agent.needs_human`, `agent.limit_reached` and `agent.gone` as kinds of their own for routing. A status that flips back inside the window emits nothing, and a restart or live handoff does not repeat the last announcement. Read them with `events.read` or `flk events wait --kinds agent.phase_changed --subject <agent id>`. Older servers skip the new kinds in the log (#1027)
