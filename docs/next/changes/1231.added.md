- `flk owner bind|unbind|list|show`, the operator's verbs over the owner bindings of #1196 (ADR-0035 §1, #1231). `bind` takes the repo's GitHub slug, `--checkout`, `--harness claude|codex|opencode`, an optional `--model` and a repeatable `--profile`; each verb prints the server's reply, and under `--json` an error is the ADR-0029 envelope. `bind` and `unbind` run from an agent's pane, a mesh relay or an unattested caller are refused with `operator_only` and exit 13 (cooperative only until agents run as their own Unix user, #1208). `unbind` and `show` of an unbound repo exit 4. A flag given without its value (`--checkout --harness claude`) is a usage error, exit 2. `flk owner policy` (#1195) is unchanged.
