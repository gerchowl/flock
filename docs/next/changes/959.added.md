- flock now records which agent started which. When `agent.start`, `agent.spawn` or `agent.fork` is called from inside an agent's pane, the server writes an `agent_delegated` event to the durable event log naming that agent as the new agent's architect. The architect comes from the caller's process ancestry, never from a parameter. Every server start, including a live handoff, re-issues each still-open edge (`reissued: true`) so log rotation cannot drop it. An edge stays open while its delegate is live, or while a removed delegate's worktree is still on disk. `flk delegate start --label TEXT` (default: the delegate's name) labels the edge and is sent only to a server advertising the `agent_start_label` capability. A start from outside any agent pane records nothing, and `agent.start` returns `edge: none (unattested)`, which `flk delegate start` prints. New edges also show in `flk digest` (#959)
