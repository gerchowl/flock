- Shared CLI socket exchanges no longer wait indefinitely: safely retryable timeouts return exit 124; dispatched mutations report outcome unknown with exit 14 and require inspection before retrying. Status timeouts also return typed exit 124 instead of an untyped failure. These changes affect scripts that branch on exit codes. Input writes reserve the server default or explicit write budget, confirmation window and transport margin; live handoff reserves its synchronous server phase budgets. Relay/subscription and remaining session/probe paths follow in #2180 and #2181.
