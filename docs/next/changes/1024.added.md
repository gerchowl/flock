- Global `--format json|text`, with `--json` as its synonym, accepted by every verb anywhere before a `--` (ADR-0029 §3). Verbs keep their default output; `--format text` picks a verb's text form where it has one. `pane read` and `agent read` keep their own `--format text|ansi` (#1024).
- Under `--json` / `--format json`, an error prints on stdout as `{"id", "error": {"code", "message", "retry", "exit", "data"}}`, with the code's retry class and the command's exit status, and a one-line `error: <code>: <message>` on stderr, so a pipe into a JSON parser always has a document (ADR-0029 §4). No server is `transport`, the version gap `server_version_gap` (exit 78). An `unconfirmed` / `abandoned` send's result goes to stdout under `--json`. Without `--json` nothing changes. No exit code changes value; usage errors outside `delegate` and some verb-local failures do not print the envelope yet (#1150) (#1024).
- MCP tool errors carry `data.retry` and `data.exit` beside `data.refusal`, from the same registries as the CLI (#1024).
