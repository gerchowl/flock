- `flk worktree create --base` and the TUI's new-worktree dialog refresh the base from its remote the same way `delegate start --base` does, through one shared resolver, so a local `dev` nobody pulled no longer decides what a new worktree starts from (#938). `worktree create` prints the ref and commit it used.
- A tag base (`--base v1.0`) is no longer fetched as if it were a branch; it is used as written and its commit is reported. A branch the remote lacks is detected by `git ls-remote --exit-code` instead of git's English error text, and an unreachable remote is reported after one bounded wait.
- `flk delegate start --json` prints a `start_failed` outcome carrying the agent pane's last lines as `data.pane_tail` (and `ready_timeout` carries them too), and `--keep-on-failure` now also keeps the workspace and checkout when the server refuses to start the agent.
