- `flk agent send --submit` (and every guarded submit, including `pane.submit` and idle wakes) now names the case where the composer swallowed Enter: when no turn starts after the Enter retry and the composer still shows the sent text, the outcome is `unconfirmed` with `reason: "typed_not_submitted"` instead of `confirm_timeout` (#1018). The text is still in the composer, so clear or inspect it before retrying. It stays a `reason` under `unconfirmed`, so the exit code is 8 as before, on new clients and on clients older than the server alike. `confirm_timeout` remains the reason when the composer no longer shows the text but no turn was observed (ADR-0029 §1).
