- The server now keeps a goal record per agent (ADR-0030 §1, ADR-0031), the first slice of goal supervision (#1034). Nine new durable event kinds record it: `goal_armed`, `goal_amended`, `goal_status_set`, `goal_subtask_changed`, `goal_verdict`, `goal_met`, `goal_paused`, `goal_resumed` and `goal_disarmed`. Each is keyed by the agent's id, not a pane. The record is folded from the log once per server start, in the same read as the delegation edges, and every open goal is re-issued on start and after each log rotation so a quiet goal is never rotated out. Removing an agent disarms its goal. Nothing writes goal events yet: the `goal.*` verbs, `flk goal` and the MCP tools come in #1155 and #1156. Servers from 2.0.0 skip these kinds; a 1.x server quarantines a log that holds them, so every server sharing a log must be 2.0.0 or newer before goals are armed.
